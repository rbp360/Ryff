# Feature Documentation Rule

Every time you successfully implement or add a new feature to this codebase, you MUST:
1. Locate and update [`Ryff_features.md`](file:///c:/Users/rob_b/Ryff/Ryff_features.md).
2. Add a new entry detailing:
   - **User & Marketing Overview**: Feature name, date, and a brief description of what was added so that it is clear to the user and can be used for marketing.
   - **Technical Details**: Brief description of the technical details (code, APIs used, etc.) so that it is clear to developers what does what.
   - **White-Label & Domain-Agnostic Utility**: A short description of this feature that makes it suitable for a white-label re-issue of this project (covering any topic, not just guitars). For example, the Reverb price logger could be used against Amazon or eBay, or the rig logger could track miles on running shoes or maintenance on vehicles.
3. Save [`Ryff_features.md`](file:///c:/Users/rob_b/Ryff/Ryff_features.md) before concluding your task.
